# Art

Generated placeholder sprites are written to `Art/Generated/` by **Tools > TRYKLI > Setup Project** (PNG baked from `PlaceholderArt`).
To use final art: replace a PNG in `Art/Generated/` (keep the name and import settings) or assign another sprite in
`Resources/TrykliSpriteLibrary.asset` (one entry per `ArtId`). No code change is required.
